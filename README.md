# Data Leadership Tools

Practical tools for data engineering managers and architects — for the people and process side of running a data team, not just the technical side.

---

## Tools

| Tool | What it does | Status |
|------|-------------|--------|
| [prioritization-board](./prioritization-board/) | Team-driven roadmap prioritization — ICs submit ideas, everyone votes, leadership gets a real signal | In progress |
| [skill-map](./skill-map/) | Personal skill growth tracker — drag to rate each skill, save snapshots, watch your shape expand over time. Opt-in sharing for team view | In progress |
| team-perception | Framework for understanding team dynamics — balancing challenge and support | Planned |

---

## Why this exists

Most data leadership content is about pipelines and platforms. The harder problems are often about people — knowing what the team actually cares about, understanding where the skill gaps are, and reading the room on team health.

These tools started as things I built or sketched out for my own teams. Sharing them here in case they're useful to others.
